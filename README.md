# Quant Analysis Algos

An early-stage collection of lightweight tools for monitoring and analysing portfolio risk and volatility. The repository contains a small app and dashboard for running analyses plus modules focused on risk monitoring, Value-at-Risk (VaR) calculations, and volatility estimation. This project is intended as an exploratory toolkit to prototype risk workflows and backtesting.

## Current project files

- `app.py`
- `dashboard.py`
- `test-nb.ipynb`
- `modules/__init__.py`
- `modules/risk_monitor.py`
- `modules/VaR_monitor.py`
- `modules/volatility.py`

## Next steps

- **VaR method options:** Implement and compare `Historical` and `Delta-normal` VaR approaches.
- **Stress & scenario testing:** Add stress-testing and scenario-analysis workflows for extreme market conditions.
- **Options volatility and backtesting:** Implement option-implied/realized volatility models and backtest option strategies and volatility forecasts.
